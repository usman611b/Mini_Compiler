# Mini Compiler — Coursework Archive

> **Compiler-construction project placeholder**

This repository is reserved for compiler-construction work exploring the path from source text to intermediate representation.

The project work covers concepts such as lexical analysis, parsing, syntax structure, symbol handling, intermediate-code generation, control-flow constructs, semantic checks, and basic optimization.

